# Tani Baik Dashboard

"Gunakan gambar terlampir sebagai referensi dasar untuk UI/UX-nya. Buatkan saya prototype web app 'Tani Baik' (Sistem Manajemen Integrated Farming & POS UMKM).

Gunakan gaya SaaS modern, warna dominan Emerald dan Slate, layout responsif, data-dense, dengan sidebar navigasi.

Buat 5 halaman utama:

Dashboard Utama: Berisi grafik batang/line hasil panen (satuan Kg & Ekor), metrik Profit margin, dan dummy layar pantau CCTV kebun.

Manajemen Kebun: Tabel/Grid untuk monitor Blok 1-3 (Manggis, Jambu, Sayur) beserta form input hasil panen dan kalkulasi ongkos pemetik (Rp 2.000/kg).

Manajemen Peternakan: Monitor stok hewan (Sapi, Ayam, Ikan) dan modul form Manajemen/Pembelian Pakan.

POS / Kasir UMKM: (Gunakan struktur persis seperti gambar terlampir) Ada menu Transaksi Penjualan, Penerimaan Barang, Manajemen Produk, dan Stok Opname.

Laporan Keuangan: Kalkulasi Harga Jual vs Biaya Operasional = Profit.

Gunakan dummy data Bahasa Indonesia. Jangan koneksikan ke Supabase dulu. Fokus 100% pada merakit UI Frontend yang interaktif dan elegan."
